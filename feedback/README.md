# Website Feedback (สำหรับ Cursor)

ลูกค้าแจ้งแก้ไขผ่านโหมด Preview → ระบบบันทึกที่นี่

| ไฟล์ | ใช้ทำอะไร |
|------|-----------|
| `feedback.json` | รายการ feedback ทั้งหมด (แหล่งความจริง) |
| `FEEDBACK.md` | สรุปแบบ Markdown อ่านง่าย |
| `images/FB-XXX.png` | Screenshot ตอนแจ้ง |

## วิธีให้ลูกค้าใช้

1. แอดมินเปิด `/admin/feedback.php`
2. คัดลอกลิงก์ Preview ส่งให้ลูกค้า (ตั้งรหัสผ่านได้)
3. ลูกค้ากดปุ่ม **แจ้งแก้ไข** → คลิกส่วนที่ต้องการแก้ → กรอกฟอร์ม → บันทึก

## หมายเหตุความปลอดภัย

- โฟลเดอร์นี้ถูกบล็อกจากเว็บ (`Require all denied`)
- ภาพดูได้เฉพาะแอดมินผ่าน `/admin/feedback_image.php`
- โหมดแจ้งแก้ไขไม่โหลดบน Production สำหรับผู้ใช้ทั่วไป
