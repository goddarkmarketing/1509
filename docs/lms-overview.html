ภาพรวมระบบ

เหมาะกับสถาบันสอนออนไลน์ที่ต้องการมีเว็บขายคอร์ส พื้นที่เรียน และหลังบ้านบริหารในที่เดียว

  • รองรับคอร์สวิดีโอ (Recorded)
  • รองรับคลาสสด (Live) และ Hybrid
  • ชำระเงินหลายช่องทาง
  • แจ้งเตือนผ่านอีเมลและ LINE

ฟังก์ชั่นในระบบ

สรุปรายการหลักที่ผู้เรียนและผู้ดูแลใช้งานได้

ฝั่งผู้เรียน

  • สมัครสมาชิก / เข้าสู่ระบบ / ลืมรหัสผ่าน
  • ดูคอร์ส ค้นหา และดูรายละเอียดคอร์ส
  • ตะกร้าสินค้า ซื้อหลายคอร์สพร้อมกัน
  • ใช้คูปองส่วนลด
  • ชำระเงิน: โอนธนาคาร + แนบสลิป
  • ชำระเงิน: PromptPay QR
  • ชำระเงิน: บัตรเครดิต/เดบิต (Omise)
  • เรียนวิดีโอ + ติดตามความคืบหน้า
  • จองรอบคลาส Live + เข้า Zoom
  • ทำแบบทดสอบ (Quiz)
  • รับใบประกาศนียบัตรเมื่อเรียนจบ
  • โปรไฟล์: คอร์สของฉัน / การจอง / ใบประกาศ
  • เชื่อม LINE OA เพื่อรับแจ้งเตือน

ฝั่งผู้ดูแล (Admin)

  • แดชบอร์ดภาพรวม
  • จัดการคอร์ส บทเรียน ปก และเอกสาร
  • สร้างตารางคลาส Live / Hybrid
  • จัดการการจองคลาส (ยืนยัน / ยกเลิก)
  • ตรวจสอบการชำระเงิน (ยืนยัน / ปฏิเสธ)
  • เปิดสิทธิ์เรียนหลังอนุมัติชำระเงิน
  • จัดการนักเรียนและสิทธิ์การเรียน
  • สร้างแบบทดสอบและคำถาม
  • จัดการคูปองส่วนลด
  • จัดการข่าวสาร / เนื้อหาเว็บไซต์
  • ดูรายงานยอดขายและการลงทะเบียน
  • ตั้งค่าเว็บ การชำระเงิน อีเมล LINE Omise
  • สำรองข้อมูลระบบ

ประเภทคอร์ส

เลือกใช้ตามรูปแบบการสอนของสถาบัน

Recorded

เรียนวิดีโอย้อนหลังได้ตามสะดวก พร้อมล็อกบทเรียนและติดตามความคืบหน้า

Live

จองรอบเรียน จำกัดจำนวนที่นั่ง และเข้าเรียนผ่านลิงก์ Zoom เมื่อยืนยันแล้ว

Hybrid

รวมทั้งวิดีโอและคลาสสดในคอร์สเดียว ตามโครงสร้างที่กำหนด

การชำระเงินและการเชื่อมต่อ

รองรับการขายจริง พร้อมแจ้งทีมงานและผู้เรียนอัตโนมัติ

  • โอนธนาคาร + อัปโหลดสลิป
  • PromptPay QR บนหน้าชำระเงิน
  • บัตรเครดิต/เดบิต ผ่าน Omise
  • แจ้งเตือนอีเมล และ LINE
  • ลิงก์ Zoom ในรอบคลาส Live
  • คูปองส่วนลด
